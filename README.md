# Доступные инструменты

Каталог того, что у нас уже сделано и что можно взять повторно, не собирая заново.

Здесь лежат инструменты и рецепты. Код бота, файлы Агента, ключи и материалы проектов сюда **не попадают** — они в приватных репозиториях.

---

## Создать нового Агента с Telegram-ботом

**`создать-агента/развернуть-агента.sh`**

Разворачивает на чистом сервере: Node.js, Claude Code CLI, VS Code CLI, отдельного пользователя `agent` с рабочими папками, код бота, токен, системный сервис с автозапуском.

**Запускается на компьютере, а не на сервере.** Это важно: код бота берётся из локальной копии приватного репозитория, поэтому открывать его наружу не нужно.

```bash
./развернуть-агента.sh \
  --ip 1.2.3.4 \
  --ключ ~/путь/к/ssh-ключу \
  --токен 123456789:AAH... \
  --код ~/путь/к/agent-bot
```

Если переносим существующего Агента — добавьте папку с его файлами:

```bash
  --днк ~/Documents/Название-папки-агента
```

**Что нужно заранее:**

| Что | Где взять |
|---|---|
| Сервер с Ubuntu, минимум 2 ГБ памяти | любой хостинг |
| SSH-ключ к нему | создаётся при заказе сервера |
| Токен бота | [@BotFather](https://t.me/BotFather) → `/newbot` |
| Подписка Claude Pro или Max | отдельных ключей и доплат не нужно |

Скрипт не запускает бота: сначала нужна авторизация Claude на сервере. Инструкцию он печатает в конце сам.

## Авторизовать Claude на сервере

**`документы/авторизация-claude.md`**

Единственный шаг установки, который нельзя автоматизировать: интерфейс Claude принимает только живое нажатие клавиши, программно отправленный Enter он игнорирует.

Рабочий способ — через `tmux`: он создаёт на сервере настоящий терминал, и нажатия в нём неотличимы от живых. Проверено — работает с первой попытки.

## Собрать .docx из .md

**`документы/md2docx.py`**

Рабочий файл — markdown, он показывает историю изменений в git. `.docx` — производная для чтения, пересобирается после каждой правки.

```bash
python3 md2docx.py "Файл.md"     один файл
python3 md2docx.py               все .md в папке
```

Работает на встроенном в macOS `textutil`, ставить ничего не нужно. Переносит заголовки, таблицы, списки, цитаты, жирный и курсив.

**Одна особенность:** `textutil` при ошибке возвращает код успеха и пишет в стандартный поток ошибок. Скрипт проверяет это сам — иначе сбой прошёл бы незамеченным и на руках осталась бы старая версия файла.
